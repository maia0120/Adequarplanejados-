# Adequar Ambientes Planejados

Site institucional estático (HTML, CSS e JavaScript puros). Não precisa de build.

## Publicar na Vercel
1. Suba esta pasta para um repositório no GitHub (nome sugerido: `adequarplanejados`).
2. Na Vercel, clique em **Add New > Project**, importe o repositório e publique.
   - Framework Preset: **Other**
   - Build Command e Output Directory: deixe em branco
3. O endereço padrão será `adequarplanejados.vercel.app` (se o nome estiver livre).

## Onde editar
- `index.html`: textos e seções
- `app.js`: lista de ambientes (`AMBS`), fotos da galeria (`GALERIA`), depoimentos (`QUOTES`)
- `styles.css`: cores e animações
- `assets/`: logo, fotos, prints de avaliações e logos das redes

Pendências do protótipo: texto de "Quem somos" (história, missão e valores) e mapa do Google Maps.
